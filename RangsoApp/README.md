# RangsoApp

This folder will include the source code for the iOS app.

## Development Tools
Language: Swift
UI Framework: SwiftUI
IDE: Xcode

## Folder Structure

As we develop the app the source files will be organised into folders:

- App -> The starting point of the app.
- Views -> UI Screens/components.
- Models -> Data models for art and feedback.
- Services -> Image processing/AI feedback.
- Resources -> Any assets/resources.

This will be decided when developing the app in Xcode.
