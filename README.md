# Rangso 

**Supporting artistic growth through technology.**

Rangso is an AI-assisted art feedback application designed to help beginner artists understand their artwork, identify areas for improvement, and develop their creative skills.

Rather than generating artwork or replacing artistic expression, Rangso aims to use technology as a supportive learning tool that encourages artistic growth and development.

## Project Overview

Beginner artists can sometimes struggle to recognize areas of improvement in their artwork or understand how to approach them.

Rangso aims to address this by allowing users to upload their artwork, select a specific artistic concern, and receive constructive, targeted feedback.

## Core Features (Planned)

- Artwork importing
- Selection of specific artistic concerns
- AI-assisted artwork feedback
- Supportive suggestions for artistic improvement

## Technologies

- **Swift** — Application development
- **SwiftUI** — User interface
- **PhotosPicker** — Artwork importing
- **Core Image** — Image processing
- **AI integration** — Planned feedback functionality

## Project Goals

- Make constructive art feedback more accessible.
- Encourage independent artistic development.
- Explore ethical applications of AI in art education.
- Support creative expression rather than replace it.
