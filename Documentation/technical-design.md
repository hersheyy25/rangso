# Rangso ~ Technical Design

## 1. Overview

This is an iOS app that will help beginner artists get useful specific feedback on their art.

## 2. Technologies Used

Application:
- Swift -> Programming Language.
- SwiftUI -> UI Framework.

Image Processing:
- PhotosPicker -> How users will select images.
- Core Image -> Maybe using this for image processing.

AI Feedback:
- AI integrated into the application. This will give users useful feedback based on what they have selected for their art and what area of artists they want feedback for. Currently looking into how to implement this.

## 3. Workflow
1. Open App.

2. Select Art Image.
3. Select Area of Artists (E.g. Colour composition).
4. Process all the given information.
5. Provide useful feedback and suggestions.

## 4. Design Criteria

Help encourage artistic growth.
Feedback should be helpful and easy to understand.
Encourage creativity by helping the artists make decisions.
Use of AI should be done responsibly. Consider what limits AI can have with providing feedback and ensure theres no presenting subjective feedback as facts.

## 5. Current Status

Currently working on the architecture of the app and how to integrate AI. As building and testing begins: will update technical decisions.

## 6. Future Ideas

Define the architecture for app.
Research how to incorporate AI into app within the budget.
Enable users to select their image with a UI.
Create a way to measure the quality of feedback provided.
Test the functionality of the app.
